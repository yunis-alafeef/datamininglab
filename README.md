# Apriori & Association Rule Mining Platform

منصة عربية تفاعلية لتعلّم خوارزمية **Apriori** واكتشاف مجموعات العناصر المتكررة وقواعد الاقتران خطوة بخطوة. تم تطويرها انطلاقاً من مستودع `datamininglab` التعليمي، مع إضافة مختبر Apriori فوق الخوارزميات التعليمية السابقة دون حذفها.

![لوحة Apriori](docs/apriori-dashboard.jpg)

## المزايا

- قاعدة TDB افتراضية مطابقة للمثال التعليمي:
  - `100 → {1, 3, 4}`
  - `200 → {2, 3, 5}`
  - `300 → {1, 2, 3, 5}`
  - `400 → {2, 5}`
- قيم افتراضية قابلة للتعديل: `minsup = 50%` و`minconf = 70%`.
- عرض تفاعلي للمراحل `C1/L1` و`C2/L2` و`C3/L3` مع عدد الظهور والدعم وقرار `Selected / Pruned`.
- توليد قواعد المجموعة `{2, 3, 5}` مع حساب الثقة الرياضي لكل قاعدة من `R1` إلى `R6`.
- إبراز القواعد القوية، وخريطة SVG للعلاقات بين العناصر.
- تعديل وإضافة وحذف المعاملات مباشرة من جدول TDB.
- استيراد ملفات `CSV` و`XLSX` و`XLS` مع اختيار عمود المعرّف وعمود العناصر.
- تصدير التقرير إلى `PDF` عبر الطباعة، أو `XLSX`، أو `CSV`.
- واجهة عربية RTL مع وضع ليلي وفاتح وتصميم متجاوب.
- جميع الحسابات تتم محلياً داخل المتصفح؛ لا يتم رفع بيانات المستخدم إلى خادم.
- تبقى الخوارزميات السابقة متاحة من زر **الخوارزميات السابقة**:
  - ID3
  - C4.5
  - Prism
  - Naïve Bayes
  - FP-Growth
  - ROC Curve
  - Evaluation

## منهجية Apriori

1. **Scan 1:** إنشاء `C1` من العناصر المفردة وحساب الدعم، ثم الاحتفاظ بالعناصر التي تحقق `minsup` في `L1`.
2. **Scan 2:** توليد الأزواج من `L1`، ثم تطبيق مبدأ Apriori وحذف الأزواج غير المتكررة لتكوين `L2`.
3. **Scan 3:** توليد الثلاثيات من الأزواج الناجحة، وينتج المثال المجموعة `{2, 3, 5}` بدعم يساوي `2/4 = 50%`.
4. **قواعد الاقتران:** تفكيك المجموعة إلى مجموعات جزئية غير خالية وحساب:

   `Confidence(X → Y) = Support(X ∪ Y) / Support(X)`

في القيم الافتراضية تكون القواعد `R1` و`R2` و`R3` قوية بثقة `100%`، بينما تكون `R4` و`R5` و`R6` أضعف بثقة `66.7%`.
